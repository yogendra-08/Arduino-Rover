# Media

Place project images and videos here.

| Folder | What goes there | Suggested names |
|--------|-----------------|-----------------|
| `diagrams/` | Circuit and wiring diagrams. `wiring.svg` is already included | `wiring.svg`, `breadboard-photo.jpg` |
| `screenshots/` | Android app screenshots, Tinkercad screenshots, Serial Monitor output | `android-app.png`, `tinkercad-circuit.png` |
| `videos/` | Short demo clips | `demo.mp4` |

Tips:

* Keep images under about 1 MB each (compress or resize phone photos).
* GitHub rejects files over 100 MB and warns above 50 MB. For long videos, upload to YouTube and link it from the README, or attach the file to a GitHub Release.
* Show an image in the README with `![Rover photo](media/screenshots/rover.jpg)`.
* Do not commit photos that show private information.
